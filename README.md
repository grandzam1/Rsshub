## Introduction

RSSHub is the world's largest RSS network, consisting of over 5,000 global instances.

RSSHub delivers millions of contents aggregated from all kinds of sources, our vibrant open source community is ensuring the deliver of RSSHub's new routes, new features and bug fixes.

## Local Windows test guide

This repository is a lightweight Windows-friendly checkout of RSSHub at commit `a049efac83eecd71da17d3193ed768210b278c57`. It intentionally does **not** include `node_modules`, `dist`, logs, Redis data, PID files, or generated test output. Those are created locally when needed.

### Requirements

Install:

- Git for Windows
- Node.js 24 LTS or a compatible Node 24 release
- Corepack, included with modern Node.js
- pnpm 12
- Optional: Docker Desktop if you want Redis caching on Windows

PowerShell setup:

```powershell
git clone https://github.com/zamtls15/rsshub-sandbox-fixed.git
cd rsshub-sandbox-fixed
corepack enable
corepack prepare pnpm@12.21.0 --activate
pnpm install
pnpm build
```

Start RSSHub without Redis:

```powershell
$env:NODE_ENV = "production"
$env:PORT = "1200"
pnpm start
```

Open `http://127.0.0.1:1200/`. The server should return the RSSHub welcome page. In a second PowerShell window, test a public route:

```powershell
Invoke-WebRequest http://127.0.0.1:1200/github/repos/DIYgod
```

### Optional Redis on Windows

Redis is optional for a basic test. For caching, Docker Desktop is the simplest Windows setup:

```powershell
docker run --name rsshub-redis -p 6379:6379 -d redis:7-alpine
$env:REDIS_URL = "redis://127.0.0.1:6379"
$env:NODE_ENV = "production"
$env:PORT = "1200"
pnpm start
```

Stop and remove Redis when finished:

```powershell
docker stop rsshub-redis
docker rm rsshub-redis
```

### Test helpers

The reusable scripts are in [`tools/`](./tools/):

- `test-routes-v2.mjs` tests the curated route matrix and writes JSON/CSV results.
- `random-verify-v3.mjs` selects source-documented public routes using two deterministic seeds and compares RSSHub output with upstream responses. Run it from the repository root:

```powershell
node tools/random-verify-v3.mjs
```

- `soak-v3.mjs` exercises rotating routes and Redis. The request loop works on Windows, but its detailed process/disk sampling uses Linux commands such as `ps`, `du`, and `/proc/net/dev`; run that detailed resource mode in WSL or Linux. On Windows, use Task Manager and Docker statistics for resource measurements.

### Important limitations from sandbox testing

- Reddit routes were not present in this checkout/upstream `master`.
- The current GitHub trending route requires parameters, for example `/github/trending/daily/javascript/en`.
- Pixiv routes require `PIXIV_REFRESHTOKEN`.
- Some Medium routes require a login cookie.
- Bilibili dynamic feeds, Substack feeds, and some government sites may reject a cloud/sandbox IP with anti-bot or HTTP 403/412 responses.
- Never commit cookies, API keys, tokens, Redis dumps, `.env` files, or generated runtime logs.
